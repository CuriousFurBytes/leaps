## A

### algorithm

**Definition:** A finite, step-by-step procedure for solving a problem or accomplishing a task. An algorithm must have clearly defined inputs, a defined sequence of steps, and produce a deterministic output.

**Also known as:** procedure, method, recipe (informally)

**Related:** [[data-structure]], [[complexity]], [[pseudocode]]

**Example:**
Binary search is an algorithm that finds a target value in a sorted array by repeatedly halving the search space, achieving O(log n) time complexity.
