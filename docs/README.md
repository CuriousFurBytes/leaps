# Documentation

This directory contains meta-documentation about leaps itself: how it is designed,
why it is designed that way, and how to get the most out of it as a human learner or
an AI agent.

---

## Contents

| File | What It Covers |
|---|---|
| [educational-philosophy.md](educational-philosophy.md) | The learning science principles behind leaps — spaced repetition, active recall, the Feynman technique, and more |
| [obsidian-setup.md](obsidian-setup.md) | How to use this repository as an Obsidian vault — plugins, graph view, Dataview queries, templates |
| [ai-agents-guide.md](ai-agents-guide.md) | How AI agents should navigate and contribute to leaps — structure, quality standards, common mistakes |

---

## Architecture Decisions

Structural decisions about the repository layout are recorded inline in
[CONTRIBUTING.md](../CONTRIBUTING.md) under the "Design Decisions" section.
If a decision warrants extended rationale, a standalone `docs/decisions/` note may
be added, but most decisions are best kept close to the thing they govern.

---

## Who This Is For

- **Human learners** new to leaps: start with [educational-philosophy.md](educational-philosophy.md)
  to understand what makes this repository different from a bookmark collection or a wiki.
- **Obsidian users**: see [obsidian-setup.md](obsidian-setup.md) for the recommended
  vault configuration, plugin stack, and Dataview queries.
- **AI agents** contributing content: [ai-agents-guide.md](ai-agents-guide.md) is required
  reading. Also read [AGENTS.md](../AGENTS.md) in the repository root.
- **Contributors** improving the repository structure: read [CONTRIBUTING.md](../CONTRIBUTING.md)
  first, then return here for context on the why.
