# Using leaps with Obsidian

leaps is designed to work as an Obsidian vault without any modification to the
repository structure. This guide covers setup, the recommended plugin stack, useful
Dataview queries for tracking your learning progress, and tips for getting the most
out of the graph view.

---

## 1. Setting Up the Vault

### Installation

1. Install [Obsidian](https://obsidian.md) (free, available on macOS, Windows, Linux,
   iOS, and Android).
2. Clone the leaps repository to your local machine:

   ```bash
   git clone https://github.com/your-username/leaps.git
   ```

3. In Obsidian, select **Open folder as vault** and choose the cloned `leaps/` directory.
4. When prompted about community plugins, click **Trust author and enable plugins** if
   you plan to use the recommended plugin stack (see below). Otherwise, enable them
   one-by-one from Settings → Community plugins.

### Initial Configuration

Open **Settings → Files and links** and set:

- **New link format:** Relative path to file
- **Use [[Wikilinks]]:** On
- **Detect all file extensions:** On (so notebooks show up in the graph)
- **Default location for new notes:** Same folder as current file

This ensures that links generated by Obsidian match the format used in leaps notes,
and that the `[[wiki-link]]` syntax works across the repository.

---

## 2. Enabling Wiki-Links

leaps uses `[[wiki-links]]` extensively for cross-topic connections. Obsidian resolves
these automatically — no configuration needed beyond enabling wikilinks (above).

When creating a new cross-link in a module, use the format:

```text
[[target-file-name]]           # Links to file, displays filename
[[target-file-name|Display Text]]  # Links to file with custom display text
[[target-file-name#Section]]   # Links to a heading within a file
```

The `SCRIPTS/find_broken_links.py` script validates all wiki-links in the repository.
Run it before committing to catch broken references.

## 3. Graph View Configuration

The graph view is one of leaps's best features — it makes the cross-disciplinary
connections visible at a glance.

### Recommended Graph Settings

Open the **Graph view** (Ctrl/Cmd+G) and click the filter icon:

**Filters:**
- Enable **Files** — the primary nodes
- Disable **Attachments** unless you want to see images and notebooks
- Enable **Orphans** while building out new topics (to find disconnected notes)

**Groups (Color Coding):**
Add path-based color groups to distinguish topic categories:

| Group Query | Color |
|---|---|
| `path:TOPICS/python` | Blue (#4B8BBE) |
| `path:TOPICS/rust` | Orange (#D4613B) |
| `path:SHARED/concepts` | Gold (#E8B84B) |
| `path:SHARED/glossary` | Teal (#4BB8B3) |
| `path:docs` | Purple (#9B59B6) |

**Display:**
- **Node size:** Links (nodes with more links appear larger — concept hubs emerge naturally)
- **Link thickness:** Proportional
- **Text fade threshold:** 1.5 (labels appear at closer zoom)

### Local Graph

Use the **Local graph** (Ctrl/Cmd+Shift+G on the current note) when working within
a single module. Set depth to 2 to see the module's immediate connections plus one hop.

## 4. Recommended Plugins

All plugins listed here are available through **Settings → Community plugins → Browse**.

### Core Stack (Install These First)

**Dataview** (`blacksmithgu/obsidian-dataview`)
Enables SQL-like queries over your vault metadata. Essential for progress dashboards
and topic indexes. See Section 5 for example queries.

**Templater** (`SilentVoid13/Templater`)
Inserts structured templates when creating new notes. Configure it to use
`TEMPLATES/obsidian/` as the template folder (create this directory if it does not
exist). Pair with the leaps module template for consistent structure.

**Periodic Notes** (`liamcain/obsidian-periodic-notes`)
For daily, weekly, and monthly learning journals. Configure weekly notes to auto-insert
a "topics reviewed this week" Dataview block.

**Calendar** (`liamcain/obsidian-calendar-plugin`)
Visual calendar view showing days you made notes. Useful for tracking consistency and
identifying gaps in your review schedule.

### Quality-of-Life Additions

**Outliner** (`vslinko/obsidian-outliner`)
Makes working with nested lists (like exercise sets and module outlines) more ergonomic.

**Advanced Tables** (`tgrosinger/obsidian-advanced-tables`)
Auto-formats Markdown tables. Useful when editing the topic index tables.

**Excalidraw** (`zsviczian/obsidian-excalidraw-plugin`)
Embed hand-drawn diagrams in notes. Useful for drawing mental models and data structure
diagrams that are harder to express in Mermaid.

**Obsidian Git** (`denolehov/obsidian-git`)
Auto-commits and pushes your vault changes on a schedule. Configure with:
- Auto commit interval: 30 minutes
- Commit message: `chore: auto-save vault`
- Push on commit: On

**Linter** (`platers/obsidian-linter`)
Auto-formats notes on save. Configure to match the leaps markdownlint settings —
particularly: fenced code blocks, single blank lines between sections, no trailing
whitespace.

## 5. Dataview Queries for Progress Tracking

These queries work in any note when the Dataview plugin is installed. Create a
`DASHBOARD.md` in the repository root and paste them in.

### All Modules by Status

```dataview
TABLE topic, difficulty, status, last_reviewed
FROM "TOPICS"
WHERE file.name = "README"
SORT topic ASC
```

### Modules Not Reviewed in 14+ Days

```dataview
TABLE topic, last_reviewed, difficulty
FROM "TOPICS"
WHERE file.name = "README"
  AND last_reviewed < date(today) - dur(14 days)
SORT last_reviewed ASC
```

### Module Count by Topic

```dataview
TABLE length(rows) AS "Module Count"
FROM "TOPICS"
WHERE file.folder != "TOPICS"
GROUP BY split(file.folder, "/")[1] AS topic
SORT topic ASC
```

### All Exercises Marked as TODO

```dataview
LIST
FROM "TOPICS"
WHERE file.name = "EXERCISES"
  AND contains(file.content, "[ ]")
SORT file.mtime DESC
```

### Cross-links Per Topic (Hub Detection)

```dataview
TABLE length(file.inlinks) AS "Inbound Links", length(file.outlinks) AS "Outbound Links"
FROM "TOPICS"
WHERE file.name = "README"
SORT length(file.inlinks) DESC
```

## 8. Recommended Theme

The **Minimal** theme by kepano works particularly well with leaps:
- Clean rendering of tables and code blocks
- Respects the document hierarchy enforced by markdownlint
- Available via Settings → Appearance → Themes → Minimal

Pair with the **Minimal Theme Settings** plugin for fine-grained control over line
width (set to 700px for comfortable reading of module notes) and heading sizes.

## 9. Sync and Multi-Device Setup

If you use leaps across multiple devices:

- **Git-based sync** (recommended): Use the Obsidian Git plugin with auto-commit and
  auto-pull on startup. This keeps your vault in sync with the remote repository and
  preserves your annotations as part of the public record.
- **Obsidian Sync** (paid, Obsidian's official option): Works but does not expose
  changes to the Git history. Use it if you want sync without CLI setup on mobile.
- **iCloud / Google Drive**: Works but can cause merge conflicts. Not recommended for
  active contributors.

Regardless of sync method, run `python SCRIPTS/validate_structure.py` before opening
a PR to ensure your local edits follow the repository conventions.
