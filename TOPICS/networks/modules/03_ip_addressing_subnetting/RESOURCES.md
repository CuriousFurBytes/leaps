# Resources: Module 03 — IP Addressing and Subnetting

> Resources listed here are specific to this module's content.

## Primary Resource
- [Computer Networking: Principles, Protocols and Practice](https://www.computer-networking.info/) — free networking textbook by Olivier Bonaventure.

## Official Documentation and Standards
- [RFC 791: Internet Protocol](https://www.rfc-editor.org/rfc/rfc791) — foundational IPv4 specification.
- [RFC 8200: Internet Protocol, Version 6](https://www.rfc-editor.org/rfc/rfc8200) — current IPv6 specification.
- [IANA Protocol Registries](https://www.iana.org/protocols) — canonical protocol number and parameter registries.

## Practice
- Run read-only commands such as `dig`, `ping`, `traceroute`, `ip addr`, and `ip route` on a lab machine.
- Capture only your own lab traffic when practicing with packet analyzers.
