# Projects: Module 03 — IP Addressing and Subnetting

## Project 1: Network Observation Journal
Record five safe observations from your own machine, such as interfaces, routes, DNS answers, and successful service checks. For each observation, write what it proves and what it does not prove.

## Project 2: Failure Decision Tree
Create a one-page decision tree for investigating a failed web request. Include DNS, local host configuration, routing, transport, TLS, and application branches.

## Project 3: Mini Design Review
Sketch a small network with users, a gateway, an internal service, and a public dependency. Annotate the drawing with at least three risks and three monitoring checks.
