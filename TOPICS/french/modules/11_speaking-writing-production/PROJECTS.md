# Projects: Module 11 — Speaking and Writing Production

> Project ideas for applying this module's content. See the topic-level [PROJECTS.md](../../PROJECTS.md) for larger cross-module projects.

---

_Module-specific projects will be defined when this module is fully expanded._

For now, consider these general activities based on the module topics:

1. **Writing practice:** Write 5–10 sentences using the main structures from this module. Check each sentence against the rules in the README.
2. **Recognition practice:** Find 3–5 examples of this module's structures in authentic French text (TV5Monde, RFI, Le Monde). Copy them out and annotate the grammatical features.
3. **Production practice:** Record yourself speaking 3–5 sentences using this module's vocabulary and structures. Listen back and self-correct.
