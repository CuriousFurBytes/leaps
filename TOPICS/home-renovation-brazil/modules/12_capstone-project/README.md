## Project Brief

_Full project brief to be written when this module is expanded._

The capstone project involves selecting a real or hypothetical Brazilian residence and producing:

1. **Memorial descritivo** — complete room-by-room specification
2. **Architectural plans** — before and after floor plans (even hand-drawn croquis at scale)
3. **Electrical design** — circuit layout and load calculation
4. **Hydraulic design** — supply and drain layout
5. **Itemized budget** — using SINAPI reference prices with 15% contingency
6. **Execution plan** — phased timeline with trade sequencing
7. **Caderno de encargos** — contractor briefing document

## Acceptance Criteria

A passing capstone package must:

- [ ] Cover all 7 deliverable components listed in the Project Brief
- [ ] Draw on concepts from at least 8 of the 11 teaching modules
- [ ] Include a budget using SINAPI or documented market prices
- [ ] Correctly sequence trades in the execution plan (electrical/hydraulic rough-in before wall finishes)
- [ ] Include waterproofing specification for all wet areas
- [ ] Identify all work requiring licensed professionals (ART/RRT)
- [ ] Be written clearly enough that someone without construction expertise could understand the scope
