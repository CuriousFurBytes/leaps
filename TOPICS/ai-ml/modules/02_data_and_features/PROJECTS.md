# Projects: Module 02 — Data and Features

## Mini Project

Create a small artifact that applies this module to a real decision. Keep scope narrow: one dataset, one baseline, one metric, and one written conclusion.

## Suggested Ideas

- Analyze whether a simple rule can solve a task before ML is needed.
- Build a tiny CSV-based experiment and summarize the evidence.
- Write a model-risk checklist for a familiar product.

## Submission Checklist

- [ ] Clear question
- [ ] Runnable code or reproducible calculation
- [ ] Metric or evaluation method
- [ ] Short written reflection
