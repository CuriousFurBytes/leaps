# Resources: Module 04 — Unsupervised Learning

1. **scikit-learn: Clustering** ([https://scikit-learn.org/stable/modules/clustering.html](https://scikit-learn.org/stable/modules/clustering.html))
   Complete guide to all sklearn clustering algorithms with comparison charts.

2. **"How to Use t-SNE Effectively" by Wattenberg, Viégas, Johnson** ([https://distill.pub/2016/misread-tsne/](https://distill.pub/2016/misread-tsne/))
   Interactive visual guide explaining t-SNE's hyperparameters and common misinterpretations.

3. **"Clustering: A Data Recovery Approach" by Mirkin** — Theoretical treatment of clustering as optimization.

4. **"DBSCAN Revisited" (Schubert et al., 2017)** — Practical guidance on DBSCAN parameter selection. [Verify: ACM or arXiv]
