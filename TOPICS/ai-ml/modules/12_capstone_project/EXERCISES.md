# Exercises: Module 12 — Capstone Project

## Instructions

Use these exercises as project milestones. They increase in scope and should be completed in order.

---

## Easy Exercises (1–3)

### Exercise 1
**Difficulty:** Easy
**Objective:** Define a project question that can be evaluated.

Write a one-page problem brief with users, decision context, success metric, and unacceptable harms.

---

### Exercise 2
**Difficulty:** Easy
**Objective:** Inventory data sources.

Create a data card listing source, fields, known gaps, sensitive attributes, and license constraints.

---

### Exercise 3
**Difficulty:** Easy
**Objective:** Establish a reproducible baseline.

Run a simple baseline and record the command used.

```bash
python train_baseline.py --config configs/baseline.yaml
```

---

## Medium Exercises (4–6)

### Exercise 4
**Difficulty:** Medium
**Objective:** Compare two model families.

Train two defensible models and explain why each was chosen.

### Exercise 5
**Difficulty:** Medium
**Objective:** Analyze errors.

Build an error table with at least five failure categories and proposed fixes.

### Exercise 6
**Difficulty:** Medium
**Objective:** Document reproducibility.

Write setup instructions that a peer can run from a clean checkout.

---

## Hard Exercises (7–8)

### Exercise 7
**Difficulty:** Hard
**Objective:** Design monitoring.

Define drift checks, performance alerts, and rollback criteria.

### Exercise 8
**Difficulty:** Hard
**Objective:** Perform responsible AI review.

Write a risk register covering privacy, fairness, misuse, and uncertainty communication.

---

## Expert Exercise (9)

### Exercise 9
**Difficulty:** Expert
**Objective:** Defend the complete system.

Present the project as if to technical reviewers: architecture, evidence, risks, alternatives, and future work.
