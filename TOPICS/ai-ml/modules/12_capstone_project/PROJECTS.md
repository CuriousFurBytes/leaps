# Projects: Module 12 — Capstone Project

## Main Project

Build an end-to-end AI or ML system for a realistic problem. Examples include a churn-risk triage tool, document classifier, demand forecaster, support-ticket router, or image-quality reviewer.

## Deliverables

- Problem brief and stakeholder map
- Data card and model card
- Training and evaluation code
- Error analysis report
- Monitoring and rollback plan
- Final presentation with recommendations

## Constraints

Do not ship a model that cannot be evaluated, explained to stakeholders, or rolled back safely.
