# Resources — Module 01: Quality Foundations

> Resources listed here are specific to this module's content.

## Primary Resource

- [ISTQB Glossary](https://glossary.istqb.org/) — useful for standardized testing vocabulary.

## Official Documentation

- [Python unittest documentation](https://docs.python.org/3/library/unittest.html) — reference for examples using Python assertions and test cases.
- [Playwright documentation](https://playwright.dev/docs/intro) — reference for later E2E testing concepts.

## Practice Ideas

- Read a recent bug report from a project you use and turn it into a regression test brief.
- Take one feature you know and classify possible checks as unit, integration, E2E, or exploratory.
