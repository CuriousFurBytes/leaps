# Resources: Module 03 — Monitoring, Telemetry, and Incident Response

## Primary Resource

- [OpenTelemetry Documentation](https://opentelemetry.io/docs/) — Canonical reference for modern telemetry concepts and instrumentation vocabulary.

## Official Documentation

- [PostHog Docs](https://posthog.com/docs) — Product analytics, feature flags, experimentation, and event design.
- [Datadog Documentation](https://docs.datadoghq.com/) — Infrastructure monitoring, APM, dashboards, logs, and service maps.
- [Sentry Documentation](https://docs.sentry.io/) — Error monitoring, releases, performance, source maps, and issue triage.
- [Grafana Documentation](https://grafana.com/docs/) — Dashboards, data sources, alerting, and observability visualization.

## Practice Ideas

- Instrument a toy web request with a correlation ID.
- Create a rollout policy for a fictional feature.
- Compare a product metric and a system metric after a simulated change.
