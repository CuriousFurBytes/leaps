# Projects: Module 12 — Capstone Project

## Capstone Project: Complete Vehicle Maintenance Program

Build and submit the full maintenance program described in `README.md`.

### Deliverables

- Vehicle profile.
- Safety rules.
- Inspection checklists.
- Service schedule.
- Maintenance log.
- Shop communication template.
- Risk register.
- Budget and priority plan.

### Acceptance Criteria

- Covers 12 months or 12,000 miles.
- Contains at least 15 ranked risks.
- Uses vehicle-specific sources where possible.
- Clearly labels assumptions.
- Avoids unsafe procedural detail for high-risk repairs.
