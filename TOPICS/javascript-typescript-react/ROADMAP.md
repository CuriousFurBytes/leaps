# Roadmap: JavaScript, TypeScript and React

## Learning Path

1. Build baseline fluency in how JavaScript runs in browsers and Node.js.
2. Learn modern JavaScript patterns for modules, data shaping, errors, and async work.
3. Add TypeScript to model contracts and reduce maintenance risk.
4. Move into browser APIs, React components, effects, forms, routing, and testing.
5. Finish with advanced TypeScript, performance, accessibility, production architecture, and the capstone project.

## Completion Targets

- Complete Modules 01–03 before starting React-specific modules.
- Complete at least one project or test per module.
- Use the capstone to demonstrate end-to-end professional readiness.
