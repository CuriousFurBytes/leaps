# Glossary: JavaScript, TypeScript and React

## API

An application programming interface: the contract one piece of software exposes to another.

## Component

A reusable React unit that describes part of the user interface from props and state.

## Runtime

The environment that executes JavaScript, such as a browser, Node.js, or an edge worker.

## State

Data that can change over time and influence program behavior or rendered UI.

## Type

A TypeScript description of the values a variable, parameter, property, or function may use.
