# Projects: JavaScript, TypeScript and React

## Project Ladder

1. **Counter and Formatter** — practice values, functions, and DOM output.
2. **Data Transformer CLI** — practice arrays, modules, and error handling.
3. **Typed API Boundary** — practice TypeScript models and guards.
4. **React Task Board** — practice components, props, state, and forms.
5. **Learning Sprint Planner** — final capstone project.

## Submission Guidance

Each project should include setup commands, a short design note, and at least one reflection on what changed after testing or review.
