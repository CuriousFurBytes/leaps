# Exercises: Module 03 — TypeScript Fundamentals

## Instructions
Complete each exercise in order. Exercises increase in difficulty. Submit your answers by editing this file or committing a solutions file.

---

## Easy Exercises (1–3)

### Exercise 1
**Difficulty:** Easy
**Objective:** Run a minimal example.

Create a small file that logs a meaningful value from this module and run it locally.

```javascript
console.log("module 03 practice");
```

### Exercise 2
**Difficulty:** Easy
**Objective:** Explain a concept in your own words.

Write a five-sentence explanation of the most important concept in this module.

---

### Exercise 3
**Difficulty:** Easy
**Objective:** Modify a worked example.

Change one example from the README so it handles a different input.

## Medium Exercises (4–6)

### Exercise 4
**Difficulty:** Medium
**Objective:** Implement a small utility.

Write a function that validates input, returns a useful value, and handles one edge case.

---

### Exercise 5
**Difficulty:** Medium
**Objective:** Use data structures intentionally.

### Exercise 6
**Difficulty:** Medium
**Objective:** Document a boundary.

## Hard Exercises (7–8)

**Difficulty:** Hard

### Exercise 8
