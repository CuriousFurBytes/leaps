# Module 08: React Fundamentals

> Building React applications from scratch: JSX, function components, props, `useState`, `useEffect`, rendering lists, conditional rendering, and handling events.

*This module is planned. Full content coming soon.*

## Prerequisites

- Module 07: Advanced TypeScript (or Module 06 at minimum)
- Module 05: Browser and DOM (for context on what React abstracts)

## What You'll Learn

- What React is and what problem it solves; setting up a React + TypeScript project with Vite
- JSX syntax: differences from HTML, embedding expressions, fragments (`<>...</>`)
- Function components: props interface typing, default props, children prop
- `useState`: declaring state, the setter function, functional updates, state batching
- `useEffect`: the dependency array, cleanup functions, common patterns (data fetching, subscriptions, timers)
- Rendering lists with `.map()` and the `key` prop — why keys matter
- Conditional rendering patterns: `&&`, ternary, early returns
