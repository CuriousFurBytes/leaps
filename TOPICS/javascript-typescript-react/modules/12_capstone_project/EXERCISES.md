# Exercises: Module 12 — Capstone Project

## Instructions
Complete each milestone in order. Treat each checkpoint as a project exercise and commit your work as you go.

---

## Easy Exercises (1–3)

### Exercise 1
**Difficulty:** Easy
**Objective:** Define the project problem and users.

Write three user stories for the Learning Sprint Planner.

---

### Exercise 2
**Difficulty:** Easy
**Objective:** Initialize a runnable project.

Create a React + TypeScript project and document the setup commands.

---

### Exercise 3
**Difficulty:** Easy
**Objective:** Model core data.

Define `SprintTask`, `Sprint`, and loading-state types.

## Medium Exercises (4–6)

### Exercise 4
**Difficulty:** Medium
**Objective:** Build component boundaries.

Implement task list, task card, and progress summary components.

---

### Exercise 5
**Difficulty:** Medium
**Objective:** Handle interaction.

Add status updates, filtering, and form validation.

---

### Exercise 6
**Difficulty:** Medium
**Objective:** Isolate data access.

Create an API adapter that can later be replaced by a real backend.

## Hard Exercises (7–8)

### Exercise 7
**Difficulty:** Hard
**Objective:** Add quality gates.

Add automated tests for at least one complete user workflow.

---

### Exercise 8
**Difficulty:** Hard
**Objective:** Improve accessibility and performance.

Audit keyboard navigation, labels, and avoidable re-renders.

## Expert Exercise (9)

### Exercise 9
**Difficulty:** Expert
**Objective:** Ship and justify the architecture.

Deploy or build the app, then write a retrospective explaining tradeoffs and future improvements.
