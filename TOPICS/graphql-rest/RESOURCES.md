## Official Documentation

- **[GraphQL Specification](https://spec.graphql.org/)** — The authoritative specification for the GraphQL language, maintained by the GraphQL Foundation. Essential reference for understanding what GraphQL actually guarantees vs. what is implementation-specific.
- **[GraphQL.org Learn](https://graphql.org/learn/)** — Official introduction to GraphQL concepts; well-structured and accurate.
- **[OpenAPI Specification 3.x](https://spec.openapis.org/oas/v3.1.0)** — The official OpenAPI specification. Use as reference when writing OpenAPI documents.
- **[Swagger Editor / OpenAPI Tools](https://swagger.io/tools/)** — Official Swagger tooling for editing, validating, and visualising OpenAPI specs.
- **[MDN HTTP Reference](https://developer.mozilla.org/en-US/docs/Web/HTTP)** — Mozilla's comprehensive reference for HTTP methods, status codes, headers, and concepts. The best free HTTP reference on the web.
- **[RFC 7231 — HTTP/1.1 Semantics](https://www.rfc-editor.org/rfc/rfc7231)** — The definitive specification for HTTP method semantics and status codes. Worth reading the method and status-code sections directly.
