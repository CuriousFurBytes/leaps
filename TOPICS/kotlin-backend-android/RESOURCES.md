# Resources: Kotlin Backend and Android

## Official Documentation

- [Kotlin Documentation](https://kotlinlang.org/docs/home.html) — Kotlin language and tooling reference.
- [Spring Guides](https://spring.io/guides) — Spring and Spring Boot practical guides.
- [Android Developers](https://developer.android.com/) — Android platform, Kotlin, Compose, and app architecture guidance.
- [Gradle User Manual](https://docs.gradle.org/current/userguide/userguide.html) — Gradle build concepts.
- [Apache Maven Guides](https://maven.apache.org/guides/) — Maven lifecycle and dependency management.

## Practice Strategy

- Rebuild examples from memory after reading them.
- Keep one scratch Gradle project and one scratch Maven project for experiments.
- Convert at least one backend DTO into an Android UI state model.
