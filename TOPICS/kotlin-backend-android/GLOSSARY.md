# Glossary: Kotlin Backend and Android

## Terms

| Term | Meaning |
|---|---|
| Android lifecycle | The sequence of app and screen states managed by the Android platform. |
| Build wrapper | A checked-in script that pins a build tool version for reproducible commands. |
| Coroutine | A suspendable unit of Kotlin work commonly used for asynchronous flows. |
| DTO | A data transfer object used to carry data across process or layer boundaries. |
| Spring Boot | A Spring-based application framework that reduces setup for production JVM services. |
