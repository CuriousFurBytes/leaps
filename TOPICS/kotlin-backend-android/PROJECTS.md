# Projects: Kotlin Backend and Android

## Project Ladder

1. Build a CLI Kotlin task formatter.
2. Build a Spring Boot task API with in-memory storage.
3. Add persistence and validation to the task API.
4. Build an Android task list screen against fake data.
5. Connect the Android app to the backend API.
6. Complete the Module 12 capstone.

## Evaluation Rubric

- Correctness: the project does what it claims.
- Maintainability: responsibilities are separated clearly.
- Verification: tests or documented checks prove important behavior.
- Reflection: the learner explains tradeoffs and next improvements.
