# Resources: Module 01 — Introduction to Kotlin

> Verified resources specifically relevant to this module's content.

---

## Official Documentation

- **[Kotlin Basics — Official Documentation](https://kotlinlang.org/docs/basic-syntax.html)**
  The official Kotlin basics reference. Covers syntax, null safety, and functions. Read alongside this module.

- **[Null Safety — Official Documentation](https://kotlinlang.org/docs/null-safety.html)**
  Deep dive into every null safety operator. Essential reading for section 4.4.

- **[Kotlin Idioms](https://kotlinlang.org/docs/idioms.html)**
  A collection of idiomatic Kotlin patterns. Good supplement after completing this module.

- **[Kotlin Playground](https://play.kotlinlang.org)**
  Browser-based REPL. Ideal for running exercises without installing anything.

## Tools

- **[IntelliJ IDEA Community Edition](https://www.jetbrains.com/idea/download/)**
  Free. Recommended IDE for Kotlin. Has built-in null safety hints, smart cast visualization, and Kotlin REPL.

- **[SDKMAN!](https://sdkman.io)**
  Manages JDK versions. Use `sdk install java 21.0.3-tem` to install a compatible JVM.
