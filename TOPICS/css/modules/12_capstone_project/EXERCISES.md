# Exercises: Module 12 — Capstone Project

## Instructions
Treat these exercises as project checkpoints. Complete them in order and record decisions in your project notes.

---

## Easy Exercises (1–3)

### Exercise 1
**Difficulty:** Easy
**Objective:** Define the project audience.

Write a one-paragraph brief for the site audience and purpose.

### Exercise 2
**Difficulty:** Easy
**Objective:** Inventory content sections.

List the six required sections and the content each section needs.

### Exercise 3
**Difficulty:** Easy
**Objective:** Establish design tokens.

Create custom properties for color, spacing, and typography.

```css
:root {
  --space-4: 1rem;
}
```

## Medium Exercises (4–6)

### Exercise 4
**Difficulty:** Medium
**Objective:** Build mobile-first structure.

Implement the page so it reads well before any media queries are added.

### Exercise 5
**Difficulty:** Medium
**Objective:** Add responsive enhancements.

Add breakpoints or container queries only where the content needs them.

### Exercise 6
**Difficulty:** Medium
**Objective:** Style states accessibly.

Add hover, active, and focus-visible states for interactive elements.

## Hard Exercises (7–8)

### Exercise 7
**Difficulty:** Hard
**Objective:** Audit CSS architecture.

Remove unnecessary specificity and document your naming strategy.

### Exercise 8
**Difficulty:** Hard
**Objective:** Test robustness.

Check narrow screens, long text, zoom, keyboard navigation, and reduced motion.

## Expert Exercise (9)

### Exercise 9
**Difficulty:** Expert
**Objective:** Defend implementation tradeoffs.

Write an architecture note explaining layout choices, token choices, accessibility decisions, and known limitations.
