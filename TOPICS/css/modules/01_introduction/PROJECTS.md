# Projects: Module 01 — Introduction and the Cascade

## Project Ideas
- Build a styled article card with clear spacing, color, and typography.
- Create a notification component with normal, success, warning, and error states.
- Redesign a plain semantic HTML page using only class selectors and low-specificity CSS.

## Acceptance Criteria
- CSS is readable and uses language-appropriate formatting.
- Class names describe purpose rather than temporary appearance.
- The result remains understandable when inspected in browser developer tools.
