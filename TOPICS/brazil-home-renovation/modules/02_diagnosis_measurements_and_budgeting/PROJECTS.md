# Projects: Module 02 — Diagnosis, Measurements, and Budgeting

> Projects turn module concepts into practical renovation artifacts. Do not perform unsafe work or regulated work without qualified professionals.

## Project Ideas

### Project 1: Room Readiness Dossier

Document one room with photos, measurements, visible risks, utility notes, and verification placeholders.

### Project 2: Wet-Area Planning Brief

Prepare a planning brief for a bathroom, laundry, or kitchen renovation emphasizing waterproofing, ventilation, and sequencing.

### Project 3: Maintenance Calendar

Build a one-year maintenance calendar for a Brazilian residence considering rain, humidity, pests, roof checks, drainage, and electrical safety.
